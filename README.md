# Industry_Growth_Trends
Which industry in California saw the highest percentage growth in total establishments between 2004 and 2007?

**Rationale for the Project**
If someone wants to start a new company, it makes sense to look at industries where they have prior expertise. However, sometimes investors want to see that there is a future, more growth to be expected, a potential for increasing YoY profits.

**Code summary**
This repo contains code that checks the number of establishments (businesses/companies) - both private and government - operating in a particular industry in 2007 compared to 2008 to see if the industry shrank or grew.
A high positive value means it grew, while a low or negative value means the industry is either actively shrinking or just going through a rough patch.

**Dataset(s) Used**
The dataset used is the official QCEW (Quarterly Census of Employment and Wages) data for California from 2004-2007, gotten from data.gov website.
